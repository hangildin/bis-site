## Правила работы
1. **Фотографии нельзя изменять генеративным ИИ**: запрещено дорисовывать или менять людей, лица, объекты, события.
2. Допустимы только технические операции с копиями: сжатие, изменение размера, кадрирование превью. Оригиналы сохранять.
3. Публиковать только факты из предоставленных материалов, без вымышленных проектов, партнёров, благодарностей, цитат и метрик.
4. Каждый проект должен открываться отдельной страницей с кратким описанием, фотографиями и при наличии ссылкой на видео.
5. Благодарности должны находиться в отдельной вкладке; оригинальный JPG/PDF открывается по нажатию.
6. Новые материалы проверять по содержимому GitHub, прежде чем просить повторную загрузку.
